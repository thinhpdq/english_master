🌐 Khi chạy Online:

Hoạt động 100% độc lập không cần Internet. Chỉ cần tải tệp HTML về máy và mở trực tiếp bằng trình duyệt, không cần cài đặt thêm phần mềm hỗ trợ hay web server.
⭐ Trình duyệt khuyến nghị:
Khuyến nghị dùng Google Chrome để được trải nghiệm tốt nhất, mượt mà nhất về động cơ giọng đọc phát âm chuẩn và giao diện tương tác.

🍎 Thiết bị iOS (iPhone / iPad)

📱 Safari & App Hỗ Trợ
🌐 Khi chạy Online:
Chỉ có thể chạy Online trực tiếp bằng trình duyệt Safari hoặc Chrome qua liên kết Online chính thức: thinhpdq.github.io/english_master ↗.
📁 Khi muốn chạy Offline:
Do cơ chế bảo mật sandbox của iOS không cho Safari/Chrome mở trực tiếp tệp HTML từ ứng dụng Tệp (Files), nên bắt buộc cài thêm phần mềm hỗ trợ để mở file HTML Offline.
💡 Khuyến nghị phần mềm chạy Offline:
Khuyến nghị dùng ứng dụng HTML Viewer Q (tải miễn phí trên App Store). Ứng dụng này hỗ trợ mở file HTML Offline cực nhanh, giữ trọn âm thanh và không bị lỗi sandbox.
